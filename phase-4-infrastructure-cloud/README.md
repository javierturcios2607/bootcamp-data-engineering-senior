# FASE 4: Infraestructura y Cloud (Semanas 13 - 16)

**Objetivo:** Desplegar infraestructuras como código en la nube (AWS/Azure), Serverless y Contenedores.

## Semanas de esta Fase:

- **[Semana 13: Cloud (AWS/Azure) - IaaS (15 Abr - 21 Abr)](./week-13-cloud-iaas/README.md)**: 🚨 Domingo de Proyecto: Crea una cuenta gratuita en AWS/Azure. Configura manualmente una red segura (VPC) y lanza una instancia pequeña. Conéctate por SSH.
- **[Semana 14: Infrastructure as Code - Terraform (22 Abr - 28 Abr)](./week-14-terraform-iac/README.md)**: 🚨 Domingo de Proyecto: Escribe un script de Terraform que cree el Bucket S3 y la instancia EC2 automáticamente. Destrúyelo (terraform destroy) al final.
- **[Semana 15: Serverless & Event Driven (29 Abr - 5 May)](./week-15-serverless-event-driven/README.md)**: 🚨 Domingo de Proyecto: Crea una Lambda que se active cada vez que subes un archivo a S3. La Lambda debe leer el archivo e imprimir cuántas líneas tiene.
- **[Semana 16: Contenedores en Nube (6 May - 12 May)](./week-16-cloud-containers-ecs/README.md)**: 🚨 Domingo de Proyecto: Sube la imagen Docker de tu ingestor (de la Fase 1) a ECR y ejecútala como una tarea en ECS Fargate programada.
