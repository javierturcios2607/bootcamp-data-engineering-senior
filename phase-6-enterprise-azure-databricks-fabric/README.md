# FASE 6: Especialización Enterprise - Azure, Databricks y Fabric (Semanas 21 - 24)

**Objetivo:** Escalar el stack hacia soluciones empresariales de Microsoft Azure, Databricks Medallion y Microsoft Fabric.

## Semanas de esta Fase:

- **[Semana 21: Ecosistema Azure Data (10 Jun - 16 Jun)](./week-21-azure-data-ecosystem/README.md)**: 🚨 Domingo de Proyecto: Crea una cuenta Free Tier en Azure. Configura ADLS Gen2 y usa ADF para orquestar una ingesta desde una API pública hacia tu Data Lake en Parquet.
- **[Semana 22: Databricks y Arquitectura Medallón (17 Jun - 23 Jun)](./week-22-databricks-medallion/README.md)**: 🚨 Domingo de Proyecto: Conecta Databricks a tu ADLS Gen2. Lee los datos crudos (Bronze), límpialos usando PySpark, y guárdalos en formato Delta (Silver).
- **[Semana 23: Microsoft Fabric y el Futuro Unificado (24 Jun - 30 Jun)](./week-23-microsoft-fabric/README.md)**: 🚨 Domingo de Proyecto: Crea un Workspace de prueba en Fabric. Configura un Lakehouse, ingesta un CSV local pesado y conéctalo en modo DirectLake a un reporte.
- **[Semana 24: El Proyecto Final Enterprise (1 Jul - 7 Jul)](./week-24-enterprise-final-project/README.md)**: 🚨 Domingo de Proyecto: Entrega y despliegue del Proyecto Final Enterprise listo para portfolio senior.
